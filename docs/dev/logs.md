# Logs Folder Documentation

The `log/` folder contains logs of the program's performance, successful downloads & errors in the programs

## Folder Overview

This folder is meant to store the logs 

---

## Files

### `error.log`
**Purpose**: Logs error in the download

### `failed.log`
**Purpose**: Logs all failed downloads 

### `success.log`
**Purpose**: Logs successful downloads

---

## Notes

- The log folder can't be imported into the main application, the main application
